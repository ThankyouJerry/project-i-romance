# 프로젝트아이 팬페이지

미연시, 수박게임, 11인 시간표를 함께 제공하는 **비공식 팬사이트**입니다. 기존 미연시 작품명은 **우리 동네, 열한 번의 우연**을 유지합니다. 저장소 이름과 GitHub Pages URL은 바꾸지 않았습니다.

- 실행 파일: `dist/`
- 검증: `node tests/story.test.cjs` 및 `node tests/visual-state.test.cjs`
- 진행 상황: 브라우저 저장소, 설정에서 파일 내보내기 지원

게임: https://thankyoujerry.github.io/project-i-romance/

저장소와 게임은 공개입니다. main 브랜치에 변경을 올리면 테스트 통과 후 dist 폴더를 GitHub Pages에 배포합니다.

## 배포 용량

2026-09-29 기준 `dist/` 전체 81개 파일의 합계는 **21,445,289바이트 (21.45 MB / 20.45 MiB)**입니다.

- WebP 이미지 52개: 15.44 MB
- PNG 이미지 3개: 3.23 MB
- 나머지 코드·폰트 등: 2.76 MB

위 수치는 배포 파일 전체의 합계이며, 첫 화면에서 모두 내려받는다는 의미는 아닙니다. 실제 전송량은 방문한 장면과 브라우저 캐시에 따라 달라집니다. 제작용 원본 이미지와 로컬 검수 페이지·스크린샷은 배포에 포함하지 않습니다.

## 게임 선택과 얼굴 수박게임

- 첫 화면: `https://thankyoujerry.github.io/project-i-romance/`
- 기존 미연시: `https://thankyoujerry.github.io/project-i-romance/?game=romance`
- 동글동글 이웃들: `https://thankyoujerry.github.io/project-i-romance/merge.html`

미연시는 같은 경로·브라우저 저장 키(`afterglow-v1`)와 기존 콘텐츠를 유지합니다. 수박게임 최고 기록은 별도 키 `neighbors-merge-best-v1`에만 저장됩니다. 진행 중인 수박게임은 새로고침/페이지 이동 시 초기화됩니다.

수박게임은 사용자 제공 원본 이미지의 얼굴을 확대한 11명을 사용합니다. 오리고기는 사용자가 다시 첨부한 노란 머리 SD 원본을 사용하며 생성 그림으로 대체하지 않았습니다. 원본 파일은 그대로 보존하고 Canvas에서 얼굴 영역만 표시합니다. 단계는 기존 캐릭터 목록 순서의 게임용 크기로, 인물의 우열·인기를 뜻하지 않습니다. 같은 단계 두 개는 다음 단계로 합쳐지고, 마지막 단계는 유지됩니다. 탭 이탈 시 일시정지되며 점선 위에 2초간 머물면 종료됩니다(생성 후 1.5초 유예).

프로필 출처: 기존 제작 자료 `game/references/sources.json`에 기록된 사용자 제공 나무위키 기본 프로필 참고 이미지. 원본 파일을 재사용하고 브라우저에서 얼굴 영역을 표시합니다. 본 게임은 비영리 목적의 팬 창작물이며, 모든 캐릭터 모델 디자인의 소유권은 프로젝트 아이에 있습니다. 별도의 권리자 허가가 확인되었다는 의미는 아닙니다. 게임 UI와 원형 물리 코드는 자체 작성했으며 외부 수박게임 코드를 사용하지 않았습니다.

추가 검증: `node tests/merge-ui.test.cjs` (입력·상태 전환·저장 분리 하네스), `node tests/merge.test.cjs` (쌍/연속/동시 충돌, 최종 단계, 입력 제한, 게임오버·초기화, 지속 시뮬레이션). 정적 배포이므로 별도 빌드나 런타임 패키지가 필요하지 않습니다.

## 같이 보는 시간 · 프로젝트 아이 시간표

- 경로: `dist/schedule.html` → 배포 후 `/project-i-romance/schedule.html`
- 별도 빌드, 서버, API 키, 외부 JS 라이브러리가 없는 정적 페이지입니다.
- 기존 사이트의 **11명**을 유지합니다: 허니츄러스, 오화요, 디디디용, 담유이, 아야, 하시요, 모네, 로즈, 포포포포, 류시호, 오리고기. 이는 사이트의 선택 명단이며 현재 공식 소속을 보증하지 않습니다. 목록 설정은 `dist/schedule-core.js`의 `MEMBERS`에서 관리합니다.
- 데스크톱은 주간 전체 보기, 모바일은 오늘 보기로 시작합니다. 전체/개별 멤버, 오늘/일별/주간, KST 날짜 이동, 시간 미정·휴방·취소·익일 종료를 지원합니다. ‘예정 시간대’는 실제 라이브 상태가 아닙니다.
- 공용 데이터는 `dist/data/schedule.json`입니다. 현재 일정은 각 항목의 출처 링크와 함께 게시합니다. `sourceType: "secondary"`는 팬 편집 캘린더에서 확인한 **2차 자료**이며 공식 원문을 확인한 것으로 표시하지 않습니다(`verified: false`). 시간·종료 시각이 불명확하면 비워 두고, 기록이 없는 날짜를 휴방으로 만들지 않습니다. 가상 데이터는 ‘예시 보기’에서만 표시됩니다. 예시는 공개용 JSON으로 내보내지 않습니다.
- 2026-10-21 KST 수집본은 10월 19~25일의 10명·45건(방송 예정 31건, 휴방 14건)을 담습니다. 달위키 각 일정 상세 페이지의 날짜를 확인했으며 공식 카페 원문은 미확인입니다. 오리고기는 해당 주의 확인 가능한 기록이 없어 미등록 상태로 두었습니다. 이는 휴방 선언이 아닙니다. 이후 변경 사항은 각 출처에서 다시 확인해야 합니다.
- 개인 편집은 `project-i-schedule-drafts-v1` 브라우저 저장소만 사용하며 게임 저장과 분리됩니다. ‘내 초안’에서는 공용 데이터 + 로컬 초안을 ID 기준으로 병합해서 보여줍니다. 직접 수정한 일정만 로컬에 보관합니다. 공용 파일이 갱신되어도 같은 ID의 로컬 초안은 그대로 우선하므로 ‘공용 시간표’ 탭으로 최신 게시 내용을 비교하세요.
- PNG 내보내기와 인쇄는 **현재 기간·멤버 필터**를 반영합니다. JSON은 **전체 공개용 데이터**를 내보내며 현재 필터로 다른 멤버를 누락시키지 않습니다. 가져오기는 검증 후 ID 기준으로 초안에 병합하고 파일에 없는 기존 항목을 삭제하지 않습니다.
- 일정 이미지는 로컬 참고용으로 열고 수동 입력합니다. 업로드, 영구 이미지 저장, OCR, 카페/X 자동 수집은 구현하지 않았습니다. 텍스트 일괄 입력은 `날짜 | 멤버 | 시작 | 종료 | 제목`을 사용하며 미정은 `-`, 익일 종료는 `+01:00`처럼 적습니다. 확인 후 초안으로 저장합니다.

### 모든 방문자에게 일정 게시하기

1. 원문을 확인하고 출처 링크·날짜·시간·취소 여부를 입력합니다. 기존 공용 일정 수정은 ‘초안으로 편집’을 누릅니다.
2. ‘내 초안’에서 JSON 내보내기를 선택합니다. 공개 전에 정확성·개인정보를 검토하세요.
3. 내보낸 JSON으로 `dist/data/schedule.json`을 교체합니다. 예시 데이터는 게시하지 마세요.
4. 테스트 후 main에 승인된 변경을 반영하면 기존 GitHub Pages 워크플로가 배포합니다. 앱은 보는 동안 60초마다 공용 JSON을 확인합니다. CDN 캐시와 배포 지연은 있을 수 있습니다.
5. GitHub에 올리기 전 로컬 초안 수정은 다른 사람에게 보이지 않습니다. 자동 소스 동기화/OCR/서버 공유 편집은 별도 구현이 필요합니다.

일정을 없애야 할 때는 원본 기록을 지우는 대신 `status: "cancelled"`로 취소를 표시할 수 있습니다. 이 페이지는 삭제 동작을 제공하지 않습니다. 브라우저 데이터 손실에 대비해 JSON을 백업해 주세요.
