# 의상·대사 및 시호 결말 검수

## 범위와 방법

최종 덮어쓰기(route-revisions)까지 적용한 실행 데이터를 기준으로 본편 88화, 외출 22개, 연애 결말 33장면, 일반 결말 11개, 캐릭터별 선물·선택 후 반응을 검토했다. 의상·색상·소품을 명시하는 문장을 해당 장면의 look 번호 및 실제 이미지와 대조했다. 읽기 전용 독립 검수 에이전트도 동일 범위를 재검토했다.

각 인물의 실제 의상은 5벌이다. look 6/7/8은 같은 옷의 표정 변형이며, 이전 look 0/1은 렌더링 시 6/7로 대응된다. 그림 밖에 놓일 수 있는 가방이나 신발이 보이지 않는다는 이유만으로 서술 오류로 판정하지 않았다.

## 저장 호환성

기존 저장의 정확히 일치하는 옛 의상 문장·장면 제목만 수정한다. 진행도, 날짜, 호감도, 선택 결과, 표시 중인 대사 순서는 유지한다. 자동 저장을 불러오는 로컬 UI에서 오리고기 6화의 옛 색상 문장이 검정 카디건·치마 묘사로 바뀌는 것을 확인했다. 같은 보정을 반복해도 추가 변경이 없다.

## 검증의 구분

- 자동: story.test.cjs / visual-state.test.cjs. 진행·저장·의상 연결·기존 문장 보정 및 진행도 보존.
- 화면: 오리고기 6화의 실제 검정 의상과 수정 문장, 기존 저장 이어하기.
- 편집: 의복·소품 명시 문장과 그림 대조. 모든 애니메이션 동작을 그림으로 추가한 것은 아니다.
- 시호 결말: 두 호칭 선택→첫 데이트→후일담을 브라우저에서 확인했다. 통합본에서는 여보 선택 후 일반 첫 페이지로 다시 접속해 이어하기(2/3)를 확인했고, 후일담(3/3)과 앨범 다시보기에도 선택한 호칭이 유지됐다.

## 배경음

장면 구분 없이 8개 사인파 음을 1.7초 간격으로 반복하던 합성 BGM과 설정 체크박스를 제거했다. 음원 대체 없이 무음으로 제공한다. 탭 숨김 시 자동저장과 시호 호칭 선택 기능은 유지했다.
