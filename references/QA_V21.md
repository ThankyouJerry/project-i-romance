# 대화 기반 선물과 수첩 반응 기록

- 11명 각 1개의 구체적인 선물, 인물 말투의 취향 발언, 수첩 단서 및 반응을 추가했다.
- 1화에서 해당 발언을 읽으면 단서가 보인다. 선물 전달은 기존처럼 첫 만남 완료 후 가능하며, 한 인물에게 한 번이고 +8(상한 100)이다.
- 선택한 말, 상대 답변, 주인공의 감상, 실제 친밀도 변화량을 선택 직후 저장한다. 선물 반응도 함께 남긴다.
- 이전 저장에는 새 감정 기록을 지어내지 않는다. 이전 진행에서 알던 취향은 기존 요약으로 보여주며 새 발언을 인용하지 않는다.
- story.test.cjs, visual-state.test.cjs, gift-notes.test.cjs 통과. 새 검사를 GitHub 검사/배포 작업에도 추가했다.
- 11명 실제 1화 발언, 단서 잠금, 기존 저장, 양/음/0 변화량, 상하한, 비용, 선물 1회 제한, 중복 기록 방지, 인물 필터 자동검증.
- 브라우저에서 오리고기 1화 선택→수첩 단서/선택기록→다음 날 선물→비용 및 답변→첫 페이지 재접속/이어하기 후 기록 2개 유지 확인.
- 내용과 UI 작업은 각각 별도 에이전트, 독립 회귀검사는 별도 에이전트로 분담. 부모가 통합 및 브라우저 검증.
