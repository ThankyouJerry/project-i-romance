# V24 수첩 취향의 출처 검증

발견: 기존 저장 호환 처리에서 1화 완료만으로 신규 선물 이름과 예전 clue를 조합해 보여줌. 실제 발언이 없는 정보가 수첩에 나타날 수 있었음.

수정: 해당 캐릭터의 실제 발언 로그가 있어야 취향을 공개. 진행도만으로 해금하지 않음. 수첩은 선물 이름/별도 해설 대신 읽은 대사 원문과 일차/에피소드 출처 표시. 발언 기록이 없는 기존 저장은 남은 본편에서 발언을 실제 읽은 뒤 해금. 완료된 과거 로그나 선택을 조작하지 않음.

11명 전원 첫 만남·발언 전후·기존 저장·다른 화자·출처·선물 비용·저장 재개 자동검사 통과. 기존 4종 테스트와 구문/diff 검사 통과. Chrome 실제 기존 저장에서 수첩 오화요 발언과 대화 기록의 동일 문장, 1일차/벽 너머의 노래 출처를 확인함.
