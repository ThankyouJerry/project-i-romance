# V25 선물 대사 문맥과 전체 이야기 연속성

## 먼저 확인한 기존 구현
- 실제 발언 로그가 있는 취향만 수첩에 공개, 일차/에피소드/원문 표시: 이미 구현.
- 문제: 선물 발언을 모든 미청취 본편 장면의 선택 직전에 자동 삽입. 질문과 선택 사이 화제가 끊어지고 후반 장면에 무관한 문장이 들어갈 수 있었음.

## 수정
- 자동 삽입 제거. 11명 첫 에피소드의 대본에 상황→취향→원래 화제→선택 순서로 직접 작성.
- 선물 자체는 기존 11개 유지. 모네 기존 퍼즐 책갈피와 새 선물은 구별. 오리고기 반응에서 선택에 따라 하지 않았을 수도 있는 과거 공동 감상을 단정하지 않음.
- 오화요 공연 후 외출은 8화 완료 후, 리허설은 공연 전날들에 해당하도록 시제 수정. 외출은 다음 날 강제 대신 공연 뒤 휴식.
- 디디디용 외출의 지원서 선행 노출 제거. 모네 2화에서 원래 책갈피를 맡기는 과정과 외출의 해석 단정 수정.
- 담유이 반찬통 중복 수령 표현 교열.
- 기록 없는 과거 저장에 거짓 취향을 부여하거나 무관한 후반 장면에 발언을 삽입하지 않음. 이미 표시 중인 저장 장면과 실제 읽은 기록은 덮어쓰지 않음.

## 검증 범위
- 별도 검토 에이전트가 유효 대본 88화·22외출·연애/일반 결말과 선물 소재 연속성을 검토. 새 도입 11개를 재검토했고 지적된 시제/중복 수령 반영.
- 자동: 4종 테스트, 11명 양 선택 후 선물 일치, 발언 직전/직후 잠금, 출처, 저장, 미청취 기존 저장, 공연 전 외출 차단, 8화 고백 조건, 구문/diff 검사 통과.
- 실제 Chrome: 오화요 첫 장면에서 수첩 비어 있음 확인, 4번째 취향 대사를 읽은 후 같은 원문/출처가 기록됨 확인, 원래 소음 질문으로 복귀해 선택지가 이어지는 것 확인. 작업 폴더 gift-dialogue-flow-verified.png.
- 전체 88화를 브라우저로 한 줄씩 수동 재플레이한 것은 아님.
